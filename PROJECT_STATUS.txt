ARCHITECTURE & DESIGN
─────────────────────────────────────────────────────────────────────────────────

System Flow:
  1. User uploads PDF
  2. BackendReceives file → Stores in Supabase Storage
  3. Extract text (PyMuPDF or OCR fallback)
  4. Send to Groq LLaMA3-8B
  5. Parse structured response
  6. Save to database
  7. Officer reviews with confidence score
  8. Approve/Edit/Reject triggered
  9. All changes logged to audit_logs
  10. Dashboard updates automatically

Security Layers:
  • Row-Level Security (database-enforced)
  • Role-Based Access (Officer/Admin)
  • CORS Protection
  • Input Validation (Pydantic)
  • Audit Trails (comprehensive logging)
  • Environment Secrets (.env)


API ENDPOINTS (8 Total)
─────────────────────────────────────────────────────────────────────────────────

UPLOAD & EXTRACTION
  POST /api/upload-pdf
    └─ Upload judgment PDF to Supabase
  
  POST /api/extract-actions
    └─ Extract structured data using Groq LLaMA3

VERIFICATION
  POST /api/approve-action/{id}
    └─ Approve extracted action
  
  POST /api/edit-action/{id}
    └─ Edit fields with human-verified values
  
  POST /api/reject-action/{id}
    └─ Reject action with reason

DASHBOARDS
  GET /api/officer-dashboard
    └─ Officer personal dashboard
  
  GET /api/admin-dashboard
    └─ Admin system analytics
  
  GET /api/cases
    └─ Get cases (filterable, paginated)

GETTING STARTED
─────────────────────────────────────────────────────────────────────────────────

1. SETUP ENVIRONMENT VARIABLES
   Create .env file in d:\JudgeAI:
   
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_KEY=your-anon-key
   SUPABASE_STORAGE_BUCKET=court-judgments
   GROQ_API_KEY=your-groq-api-key

2. INSTALL DEPENDENCIES
   
   cd d:\JudgeAI
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   
   cd frontend
   npm install
   cd ..

3. LOAD DATABASE SCHEMA
   
   - Go to https://app.supabase.com
   - Open SQL Editor
   - Run contents of backend/db_schema.sql
   - Create storage bucket "court-judgments" (Public)

4. START SERVERS
   
   Terminal 1:
   venv\Scripts\activate
   uvicorn backend.main:app --reload
   
   Terminal 2:
   cd frontend && npm run dev

5. ACCESS APPLICATION
   
   Frontend:  http://localhost:5173
   API Docs:  http://localhost:8000/docs
